# Security policy

## Reporting a vulnerability

Please report security problems privately by email to **hello@grafikui.com**, with "Security" in the subject line. Do not open a public pull request, discussion or post for a security issue.

Include what you found, how to reproduce it, and the version (`npx maddox-engine --version` or the commit SHA) you tested. We aim to acknowledge reports within 3 working days and will keep you updated until it is resolved. We are happy to credit you once a fix is released, if you would like.

## Scope

- The `maddox-engine` npm package and this repository's GitHub Action.
- The hosted service at maddoxengine.com.

## Supported versions

Security fixes are released for the latest published version only.
